# AI Learning Journey

A beginner Python project exploring how AI learns from data.

I'm learning how training, weights, parameters, and predictions work by building small AI experiments.

## Experiments

### 1. Number Learning AI
- Learns a simple numerical pattern.
- Adjusts its weight and bias.
- Saves learned parameters in a JSON file.

### 2. Word Classification AI
- Uses scikit-learn.
- Converts text into numerical features.
- Classifies sentences as positive or negative.

## Requirements

- Python 3
- scikit-learn

## Installation on Manjaro Linux

Clone this repository, then enter its folder.

Create a virtual environment:

    python -m venv .venv
    source .venv/bin/activate

Install the required library:

    python -m pip install -r requirements.txt

## Run the experiments

Number AI:

    python ai.py

Word AI:

    python word_ai.py

## Learning Goals

- Understand how AI training works.
- Learn about weights and parameters.
- Explore how AI predicts answers.
- Practice saving and loading model parameters.
- Experiment with text classification.
